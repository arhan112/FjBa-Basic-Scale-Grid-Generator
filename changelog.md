# Changelog

All notable changes to FjBa Basic Scale Grid Generator are documented here.

## [1.1.0] - 2026-11-16

### Added
- Interactive scale-based grid frame generation.
- A0, A1, A2, A3 and A4 paper formats.
- Portrait and landscape orientations.
- Rectangular and square grid options.
- Customizable frame colors, width and fill transparency.
- Grid labels and automatic numbering.
- Grid manager with rename and delete options.
- JSON configuration save and load.
- Live map canvas preview.
- Animated FjBa logo.

### Compatibility
- Minimum supported QGIS version: 3.28.
- QGIS 4 compatibility has not yet been tested.
